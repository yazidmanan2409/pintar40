# Image placeholder inventory

Every placeholder below is rendered on the page itself as a labelled dashed
box (see `shared/dom.js`'s `ph()`), sized to the real image's aspect ratio
so the layout can be judged before any photography exists. This file is
the same inventory, for planning a shoot or a stock/illustration brief in
one pass.

No final photography has been sourced. Avoid: robots, AI brains, glowing
networks, floating holograms, generic laptop stock photography, children
pointing theatrically at screens. Prefer documentary-style photography of
real Indonesian classrooms and educators over posed stock imagery.
