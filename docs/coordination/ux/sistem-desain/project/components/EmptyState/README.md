Three different sentences for three different emptinesses: not yet, not enough yet, nothing matches.

**Status: KEPT** (KartuKetiadaan's rules), restyled.

**Kinds**
- **Not yet:** a beginning. Say what will appear here and offer the first action («Siapkan materi pertama»).
- **Not enough yet:** the designed state, not a failure. Say how much there is and how much is needed («Sekarang 2 murid; perlu 5.»).
- **Nothing matches:** say what was searched and offer the way back («Hapus pencarian»).

**Rules**
- No illustrations, no sad faces, no zero standing in for an unknown.
- «Belum ada» and «Tidak untuk Anda» are different sentences; a refusal never pretends to be empty, and empty never pretends to be a refusal.
- If nothing needs attention, the section is absent, not an empty box saying so.

**In PINTAR today.** KartuKetiadaan, the evidence page's insufficient state, `.pin-empty`.
