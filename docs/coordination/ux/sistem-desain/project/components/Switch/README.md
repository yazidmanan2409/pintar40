On or off, for a setting that takes effect the moment it changes. Its state is also a word.

**Status: NEW.** PINTAR has no switch today; it is proposed only for settings saved at once.

**Markup.** `div.pds-switch-row` > the label and its help + `span.pds-switch-kata` («Aktif»/«Nonaktif») + `button.pds-switch[role=switch][aria-checked]`. The button is the 44 px target; the 44 × 24 track is drawn inside it.

**Rules**
- Only for settings saved immediately. Inside a form with «Simpan», use a checkbox.
- Say what changes and where («Berlaku untuk Kelas 5A mulai soal berikutnya.»).
- The visible word follows the state; the colour is never the only signal.
- Disabled only with its reason.
