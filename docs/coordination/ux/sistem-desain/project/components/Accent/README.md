Accent colour in PINTAR: used only where it says context, hierarchy, state or attention, and never to decorate.

**Status: NEW role, APPROVED (question 12, 5 Oct).** No new hue. Status colours communicate state with words; PINTAR green communicates hierarchy, action and selection; deep ink may identify a context that changes the meaning of the screen, such as MODE PERAGAAN.

**Each job and its colour**
- **State and attention:** the four status colours, always with a word («Selesai», «Perlu dilihat»). Already ruled.
- **Hierarchy:** `pintar-primary`. It marks the one primary action, the current selection (a filled segment, the current page), and in a chart the one value the page is about, with the others in `ink-3`.
- **Context:** the `context` band in deep ink (`ink-1`, text `surface-0`). It is for a mode that changes what the whole screen means: MODE PERAGAAN, or a preview of what a learner sees. It is one full-width band at the top with its way out on it. It looks like neither a status nor an action, so it can't be mistaken for either.

**Why no new hue (yet)**
- Green is PINTAR's identity and also success.
- Amber, red and blue are status colours.
- Plum, the family greens, teal and the warm gold belong to the card and the certificate (D-074, D-080), and those must not drift.
- Any new hue would sit beside one of these meanings and borrow it. It waits until there is a use none of them can carry.

**Rules**
- At most one accented thing in view for each job: one primary action, one context band.
- An accent always has words. Colour is never the only sign.
- Never on a person, never as celebration, never as a background for decoration.
- A learner's lesson and question screens carry no accent except the primary action.
