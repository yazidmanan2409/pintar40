A link goes somewhere: underlined in a sentence, a short bold phrase on its own, and a named way back.

**Status: KEPT,** with one change: a link inside a sentence is always underlined, so it is not told by colour alone.

**Kinds**
- `pds-link`: inside running text, always underlined (1 px; 2 px on hover), so it is not told by colour alone.
- `pds-link pds-link-quiet`: a standalone link to another page («Lihat semua kelas»), bold green, underlined on hover.
- `pds-back`: «Kembali ke Kelas 5A», with a chevron, 44 px tall. It names its destination whenever the way back is not obvious.

**Rules**
- A link goes somewhere; a button does something. Never a link that submits, never a button that only navigates.
- Link words say where they lead; never «klik di sini».
- A navigation link shows the working dot while the next page loads (TandaTautan).

**In PINTAR today.** The global `a` style, `.pin-back`, and Konfigurasi's Tailwind links.
