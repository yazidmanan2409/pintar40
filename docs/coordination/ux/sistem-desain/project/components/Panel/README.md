Type and space first; a container only when something must stand apart. Five ways to group, from no container to a card.

**Status: CHANGED.** The containers that exist today (cards, lists, wells) keep their roles; the rules for choosing between them are now written down.

**In order of preference**
1. **A section** (`pds-section`): a heading and its content, separated from the next by `space-8` and a hairline. No container.
2. **A list** (`pds-list`): rows between hairlines, for many objects of one kind.
3. **A well** (`pds-well`): `surface-2`, no border, for quiet information beside the main thing (an integrity note, an explanation).
4. **A panel** (`pds-panel`): `surface-1`, a hairline, `radius-lg`, for a group that must stand apart: a set of fields saved together, a confirmation, a table frame.
5. **A card** (`pds-card`): a panel that is one object you open, in a small collection (six or fewer). The whole card is the link.

**Rules**
- Never a box drawn round a heading and a paragraph.
- Never cards inside cards, never a panel inside a panel.
- More than six objects of one kind is a list, not a grid of cards.
- No shadow on any of these: they are part of the page.
