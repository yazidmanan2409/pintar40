What something is, never how it is doing: a subject, a level, a context, or a filter that is applied.

**Status: NEW.** A pill with a `line-strong` outline on `surface-1`: the same shape as a badge, which is filled. Every small label in PINTAR is a pill (the 4 Oct references); an outline says what something is, a fill says how it is doing.

**Kinds.** `pds-tag` (describing), and a removable filter (`pds-tag` with a 24 px remove button and its accessible name «Hapus saringan Status: Belum mulai»), followed by «Hapus semua saringan».

**Rules**
- Never coloured: a tag is not a status.
- Short: one or two words, or «SD · Kelas 5».
- A removable tag is only an applied filter; removing it changes the view at once.
