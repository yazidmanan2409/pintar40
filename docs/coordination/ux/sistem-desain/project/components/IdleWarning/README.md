**Rules**
- Attention, not error: nothing is wrong. `status-attention-soft` ground, the clock icon.
- It appears after 4 minutes without activity, at the top of the page, without covering the work.
- Any activity keeps PINTAR open; the button is for someone who is reading and not touching anything.
- `role="alert"`, so a screen reader hears it once; it never flashes or counts down second by second.
- Under reduced motion it simply appears.
