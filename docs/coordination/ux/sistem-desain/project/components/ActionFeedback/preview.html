Network (review only)

Simpan → Menyimpan… → ✓ Tersimpan

Change the name after saving: the button returns to «Simpan», because there is something new to save.

Words: «Menyimpan…» is tombol.menyimpan; «Mengirim…» is umpanbalik.form.mengirim and akun.mengirim; «Sudah terkirim» is umpanbalik.selesai.judul; the email line follows aktifkan.kode_ulang_ok («PINTAR sedang mengirim…»). The rest is sample text.

Kirim → Mengirim… → ✓ Terkirim (the server confirmed it)

Jawaban umpan balik kelas: the server stores them, then says so.

Email: Kirim → Mengirim… → «PINTAR sedang mengirim…», never ✓

Kirim ulang kartu PINTAR ke email Anda. PINTAR cannot confirm that an email arrived (D-098(c)), so it never says it was sent.
