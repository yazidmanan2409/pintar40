Buat password

Password ini dipakai untuk masuk ke PINTAR, bersama email atau username Anda.

  • Paling sedikit 8 karakter.
  • Harus berisi huruf kecil
  • Harus berisi huruf besar
  • Harus berisi angka

Password yang pernah bocor di internet tidak bisa dipakai.

Words: aktifkan.langkah / dari, p_judul, p_lede, p_min («Paling sedikit … karakter.»), p_wajib with p_k.* («Harus berisi huruf kecil»), p_bocor, p_label, p_ulang, p_simpan. The rules come from the canonical setting (BOB-26), never typed into the screen; 8 and the four kinds here are an example. An unmet rule stays plain ink, never red: nothing is wrong while someone is still typing.
