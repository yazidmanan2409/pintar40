Where am I, how much is there, and how do I move: always all three.

**Status: NEW** as a shared component (the intake's name list pages today on its own terms).

**Three patterns**
- **Under a table (the default):** «Menampilkan 21–40 dari 312 murid», «Halaman 2 dari 16», and «Sebelumnya» / «Berikutnya» buttons.
- **A report people jump around in:** page numbers with ellipses (1 … 4 5 6 … 16); the current page on `pintar-primary-soft` with `aria-current="page"`.
- **A list read in order:** «Tampilkan 50 nama lagi», with «Menampilkan 50 dari 500 nama».

**Small screens.** «2 / 16» and two icon buttons with accessible names; the words step back.

**Rules**
- Never hide the total. If it is not known, say what is shown («Menampilkan 50 nama terbaru»).
- A disabled «Sebelumnya» on the first page is fine; it is obvious why.
- Page size is fixed by the surface; no «baris per halaman» control unless people asked for one.
- Moving to a page keeps the person's place: focus goes to the current page number, or to the table.
