One grammar of states across every control: hover, pressed, focus, selected, disabled, look the same everywhere.

**Status: CHANGED** (a pressed state everywhere; one disabled look).

- **Hover:** one step of ground (`surface-2`) or of ink.
- **Pressed:** one more step (`surface-3`, or the primary's pressed green). New: v2 has hover only.
- **Focus:** the same 2 px `focus-ring` everywhere, offset 2 px (inset inside navigation, tabs and menus).
- **Selected:** `pintar-primary-soft`, or the 2 px tab underline, always with weight 600.
- **Disabled:** `surface-2` and `ink-disabled`, with its reason beside it. A place or a choice a person may never use is absent, not disabled.
- **Error** (fields): the `status-blocked` edge, drawn inside, and the message.

The Button preview shows the same grammar for the five button families.
