Native details: a summary that says whether there is anything inside, and the detail when the person asks for it.

**Status: KEPT** (native `details`, as Pimpinan uses it).

**Markup.** `details.pds-disclosure` > `summary` (a title, a `small` line that summarises, the chevron) > `div`.

**Rules**
- The summary line says what is inside («24 dari 31 sudah mengerjakan», «Belum ada hasil: Uji Cepat dibuka Jumat»), so a closed item is already useful.
- For progressive disclosure of detail, never to hide something the person must see.
- Several may be open at once; none closes another.

**In PINTAR today.** Pimpinan's per-class `<details>` (DAISY-07).
