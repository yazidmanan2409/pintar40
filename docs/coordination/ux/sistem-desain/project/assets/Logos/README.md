The PINTAR wordmark: PINTAR in Helvetica Neue 65 Medium capitals, tracking +50, in PINTAR green #245F55. It is locked (approved brand ruling, 5 Oct).

- **The master files are still to be made**, from Helvetica Neue 65 Medium and no other face. **Before they are created or distributed, the font licence is verified**: it must permit logo artwork, outlining and distributing the outlined files (see Wordmark, «Master artwork and the font licence»). Nothing is assumed about what it permits. This repository has neither the font nor the files. Each file is trimmed to the letters, with clear space X (the cap height) applied by layout:
  - `pintar-wordmark-hijau.svg`, green;
  - `pintar-wordmark-putih.svg`, white;
  - `pintar-wordmark-hitam.svg`, black;
  - the same three as vector PDFs for print: green as CMYK 84 43 65 29, black as 0 0 0 100;
  - PNG exports at 2× for email.
- **Retired:** the supplied «PINTAR SELALU» artwork (`public/brand/pintar-selalu-logo.png`, and the email's `pintar-email-logo.png`). It no longer appears in the design system. The product changes in the application pass.
- **Not a logo:** the tab icon, a plain PINTAR-green square, is in `../AppIcon/` (Q17, 5 Oct). There is no second mark.
