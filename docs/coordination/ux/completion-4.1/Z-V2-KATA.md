## The words (one string for both audiences)

New key `hasil.ulang_berjalan`:
- **ID:** «Uji Penguasaan ulang sedang berlangsung. Hasil yang tampil adalah hasil uji sebelumnya.»
- **EN:** «A Mastery Check retake is in progress. The result shown is from the earlier check.»

**Why not «Ujian ulang»:**
- **The owner's start, kept in meaning.** «… ulang sedang berlangsung» stays.
- **The name changes.** Screens name this assessment «Uji Penguasaan», never «ujian», so the status uses the same name (one term per concept).
- **The second sentence is what stops it reading as a result.** It says which attempt the figure belongs to.

## Where it sits, and how

- **Learner:**
  - on the chapter's result page (`/belajar/[tugas]/hasil`), directly under the result block;
  - on that chapter's row in Hasil Belajar.
- **Teacher:**
  - on the per-learner page, under that chapter's result row;
  - on any class view that shows that learner's result for that chapter.
- **Separate from the verdict:**
  - its own line, `pin-meta`, neutral tone;
  - outside the «Target tercapai» / «Belum mencapai target» banner;
  - no ✓, no icon, no result colour, no figure.

## When it shows

- **Only while a retake sitting of that chapter's Uji Penguasaan is open:** begun, and not yet ended.
- **Not shown when:**
  - the retake was abandoned;
  - it ended without being finalised (time out, ended by the teacher, withdrawn);
  - it is finalised. Then V2's reader shows the new completed result, and the line goes.
- **No promise about the future:** the line says nothing about replacement or timing.
